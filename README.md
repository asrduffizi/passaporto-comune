# Passaporto Comune

Il tuo atlante di viaggio personale: timbra paesi, città, comuni e isole dove sei stato, tieni la lista dei desideri e trova idee per il prossimo viaggio.

Sito: https://asrduffizi.github.io/passaporto-comune/

- `index.html`: l'app (globo, mappa dettagliata, consigli di viaggio, login).
- `luoghi.txt`: elenco di circa 135.000 città, comuni italiani e isole (dati GeoNames e Natural Earth).
- `database.sql`: tabella Supabase con sicurezza per riga, ogni utente vede solo il proprio passaporto.
